## 1. 문서 목적과 결정 상태

초기 돌·나무 생산부터 이후 자원 확장까지 사용할 아이템과 제조 관계를 정리한다. 기본 게임 규칙은 게임 기획서를 따르며, 이 문서는 품목과 생산 체인에 집중한다.

현재 정해진 방향은 돌과 나무를 채취·가공하고 두 가지 이상의 재료를 조합한 상품을 판매하는 것이다. 석판은 초기 가공품 예시다. 첫 확장 석탄, 다음 확장 철은 우선 검토 순서다. 아래 구체적인 품목과 제조법, 시설 이름은 승인 전 후보이며 확정 목록이 아니다.

추가 자원으로 구리, 금, 석유, 석영을 포함한다. 상위 티어에는 서로 다른 재료 3종과 4종을 사용하는 제작법을 도입하며, 석유는 별도의 정제 공정을 거친다. 이 방향은 확정하고, 각 자원의 해금 순서와 구체적인 파생 아이템·제조법은 후보로 구분한다.

생산 수량, 소요 시간, 판매가, 적재량과 저장 용량은 프로토타입 이후 조정한다. 초기 제조법은 실제 제조 공정 전체를 재현하지 않고 주요 재료 관계를 표현한다. 도구·접착제 등 보조 재료를 생략했다고 해서 해당 산업의 실제 제조법을 의미하지 않는다.

## 2. 아이템 선정 원칙

- 원재료는 직접 판매하거나 여러 가공 체인에 투입할 수 있게 한다.
- 가공품은 상품이면서 다음 단계의 재료가 될 수 있게 한다.
- 복합 상품은 서로 다른 자원 계열을 연결하여 도로 운송과 생산량 배분을 요구한다.
- 새로운 자원은 기존 재료와 결합해 이전 생산라인이 계속 사용되게 한다.
- 동일한 역할의 상품을 이름만 바꿔 늘리기보다 생산 분기와 합류가 생기는 품목을 우선한다.
- 건설 비용은 현재 돈이 기본이다. 상품 이름이 건축 자재라고 해서 건설에 그 상품을 의무 소비하는 규칙을 추가하지 않는다.

## 3. 초기 아이템 후보

첫 프로토타입 후보는 원재료 2종, 단일 가공품 2종, 복합 상품 1종의 총 5종이다.

| 아이템 | 획득 또는 제조 관계 | 역할과 제안 시설 |
| --- | --- | --- |
| 돌 | 돌 채취 노드에서 채취 | 첫 판매 원재료, 채석장 |
| 원목 | 나무 자원에서 채취 | 목재 계열 원재료, 벌목장 |
| 석판 | 돌을 가공 | 직접 판매 및 복합 상품 재료, 석재 가공소 |
| 판재 | 원목을 가공 | 직접 판매 및 복합 상품 재료, 제재소 |
| 석재 테이블 | 석판과 판재를 조합 | 석재 상판과 목재 구조를 결합한 첫 복합 상품, 조립 공장 |

원목은 게임 자원인 나무를 채취했을 때 얻는 물품 명칭의 제안이다. 석재 테이블은 나무·돌을 함께 사용하는 초기 상품 후보이며 최종 확정은 아니다.

초기 흐름은 돌 → 석판, 원목 → 판재, 석판과 판재 → 석재 테이블로 구성한다. 각 단계에서 직접 판매할 수 있으므로 당장 현금으로 바꿀지 다음 가공에 투입할지 선택한다.

## 4. 초기 지역의 추가 후보

다섯 품목으로 기본 생산을 확인한 후, 같은 자원으로 생산이 분기되는 재미가 필요하면 아래 후보를 추가한다. 한 번에 모두 도입하지 않는다.

| 아이템 | 제조 관계 후보 | 추가하는 선택 |
| --- | --- | --- |
| 석재 블록 | 돌을 가공 | 석판과 다른 석재 가공 경로 |
| 목재 기둥 | 원목을 가공 | 판재와 다른 목재 가공 경로 |
| 목재 상자 | 판재를 가공 | 목재 단독으로 완제품 생산 |
| 정원 벤치 | 석재 블록과 판재를 조합 | 석재 받침과 목재 좌판을 결합 |

테이블과 벤치의 제조 관계가 비슷하면 두 품목을 모두 추가할 필요는 없다. 생산시설, 발주 역할 또는 재료 수급에서 구분할 이유가 있을 때 확대한다. 목재 상자는 판매 상품이며 다른 모든 상품의 필수 포장재로 지정하지 않는다.

## 5. 석탄과 철 확장 후보

석탄은 철 제련이 가능해지기 전에도 판매 또는 가공 용도가 있어야 첫 확장의 의미가 생긴다. 초기에는 석탄 직접 판매와 연탄 생산을 후보로 두고 이후 철 제련 재료로 연결한다.

| 아이템 | 획득 또는 제조 관계 후보 | 역할 |
| --- | --- | --- |
| 석탄 | 석탄 노드에서 채취 | 직접 판매, 연료 상품과 제련 재료 |
| 연탄 | 석탄 가공 | 철 해금 이전의 판매용 가공품 |
| 철광석 | 철 자원 노드에서 채취 | 금속 생산의 원재료 |
| 철괴 | 철광석과 석탄을 제련 | 금속 가공의 공통 중간재 |
| 철판 | 철괴 가공 | 금속 제품과 후속 기계류 재료 |
| 철봉 | 철괴 가공 | 도구와 구조 부품 재료 |
| 못 | 철봉 가공 | 목재 상품과 결합하는 중간재 |
| 철제 보강 상자 | 판재와 못을 조합 | 기존 목재 생산과 철 생산의 연결 |
| 수공구 세트 | 철봉과 판재를 조합 | 목재 손잡이와 금속 부품을 사용하는 판매 상품 |

제련에 석탄을 넣는 방식은 제조법의 재료 소비 제안이다. 모든 시설에 연료나 전력 시스템을 추가하는 결정은 아니다. 철제 보강 상자와 수공구 세트도 둘 다 필수인 것은 아니며 초기 철 체인의 크기를 보고 선택한다.

## 6. 구리와 금 및 석영 계열

새 자원을 전기·전자·정밀 제품으로 연결하는 파생 품목 후보다. 아래 제조 관계는 게임용으로 단순화한 제안이며 실제 공업 공정 전체를 재현하지 않는다. 제련·용융 등에 연료를 별도 투입할지는 아직 정하지 않는다.

| 아이템 | 획득 또는 제조 관계 후보 | 역할 |
| --- | --- | --- |
| 구리광석 | 구리 자원 노드에서 채취 | 구리 계열 원재료 |
| 구리괴 | 구리광석 제련 | 구리 가공의 중간재 |
| 구리선 | 구리괴 가공 | 전선과 모터의 재료 |
| 금광석 | 금 자원 노드에서 채취 | 금 계열 원재료 |
| 금괴 | 금광석 제련 | 판매 및 정밀 부품 재료 |
| 도금 접점 | 구리괴와 금괴 가공 | 금을 전자제품 생산에 연결 |
| 석영 | 석영 노드에서 채취 | 유리와 실리콘 계열 원재료 |
| 유리판 | 석영 가공 | 기기 외장과 정밀 제품 재료 |
| 실리콘 소재 | 석영과 석탄 가공 | 반도체용 중간재 후보 |
| 실리콘 웨이퍼 | 실리콘 소재 가공 | 고급 전자 부품 재료 |

금의 역할을 고가 원재료 판매에 한정하지 않고, 도금 접점을 통해 상위 제품에 연결한다. 석영은 유리판과 실리콘 소재로 생산이 분기되는 구성을 제안한다.

## 7. 석유 채취와 별도 정제 공정

석유는 자원 지점에서 원유를 채취한 뒤 전용 정유시설에서 정제한다. 원유를 곧바로 플라스틱이나 고급 상품으로 조합하지 않고, 정제된 중간재를 후속 화학 공정에서 가공한다.

기본 체인 후보는 **원유 → 정유시설 → 나프타 → 화학시설 → 플라스틱 또는 합성고무**다. 연료유와 윤활유 계열도 판매·가공 분기로 검토한다.

| 아이템 | 획득 또는 제조 관계 후보 | 역할 |
| --- | --- | --- |
| 원유 | 석유 자원 지점에서 채취 | 정유시설 투입 원재료 |
| 나프타 | 원유 정제 | 플라스틱·합성고무의 중간재 |
| 연료유 | 원유 정제 | 판매용 정제 상품 후보 |
| 윤활기유 | 원유 정제 | 윤활유의 중간재 |
| 플라스틱 | 나프타 화학 가공 | 전선 피복과 전자제품 재료 |
| 합성고무 | 나프타 화학 가공 | 기계류의 패킹 등 재료 |
| 윤활유 | 윤활기유 가공 | 고급 기계 제조 재료 후보 |

정제 시 여러 제품을 동시에 산출할지, 제조법 선택에 따라 한 종류씩 산출할지는 미정이다. 동시 산출 방식을 채택하면 특정 부산물의 저장소가 찼을 때 정제 중단과 초과 재고 처리 원칙을 별도로 정한다. 운송 중 예외 입고를 보존하는 초과 재고 규칙을 무제한 생산 허용으로 사용하지 않는다.

액체를 수량 단위의 화물로 추상화할지, 탱크 차량이나 별도 저장 탱크를 사용할지는 후속 결정 사항이다. 파이프·배럴·용기 회수 시스템은 아직 추가하지 않는다. 운송 방식이 정해지면 유한 저장소에는 기존 입고 예약 규칙을 적용한다. 연료유를 상품으로 만든다고 모든 건물과 차량에 연료 소비를 도입하는 것은 아니다.

## 8. 제작 티어와 다중 재료 조합

재료 3종·4종은 한 품목의 수량이 아니라 해당 제작법에 직접 투입하는 서로 다른 품목 종류 수를 뜻한다. 초기에는 단일 가공과 2종 조합을 익히고, 상위 티어에서 3종·4종 조합을 사용한다. 모든 상위 품목이 반드시 3종 이상을 사용할 필요는 없으며 공정 깊이와 자원 해금도 티어를 결정한다.

다음 제작법은 전체 입력 재료를 이 문서의 후보 체인에서 확보할 수 있도록 연결한 예시다. 수량과 처리 시간은 미정이다.

| 결과 아이템 | 직접 투입 재료 후보 | 단계와 역할 |
| --- | --- | --- |
| 절연 전선 | 구리선 + 플라스틱 | 2종 중간재, 금속과 석유 체인 연결 |
| 기어 | 철괴 | 단일 가공 중간재 |
| 전기 모터 | 철판 + 구리선 + 절연 전선 | 상위 3종 조합, 기계 제품 재료 |
| 회로 기판 | 플라스틱 + 구리선 + 실리콘 웨이퍼 | 상위 3종 조합, 전자 제품 재료 |
| 정밀 제어기 | 회로 기판 + 도금 접점 + 절연 전선 + 플라스틱 | 상위 4종 조합, 금·석영·석유 체인 연결 |
| 산업용 펌프 | 철판 + 전기 모터 + 기어 + 합성고무 | 상위 4종 조합, 기계류 판매 상품 |
| 자동화 생산 모듈 | 산업용 펌프 + 정밀 제어기 + 철판 + 윤활유 | 최상위 4종 조합、다단계 생산망 통합 후보 |

3종·4종 조합시설은 모든 필수 재료가 모여야 생산을 시작한다. 한 재료의 과잉 입고가 다른 재료의 입고 공간을 모두 차지하지 않도록 품목별 저장 공간 또는 최소 공간 보장 방식을 검토한다. 저장 방식은 아직 확정하지 않으며 입고 예약은 선택한 저장 구조에 맞춰 적용한다.

여러 지역의 생산품이 같은 조립시설로 모이므로, 복합 제조의 난도는 재료 수뿐 아니라 공급량 배분과 도로·철도 물류에서 발생하도록 한다. 기존 시설 정보 화면에도 모든 투입 재료의 수량과 공급 출처가 표시되어야 한다.

## 9. 생산 체인과 메인 발주

메인 발주는 초반 가공품, 복합 상품, 금속 제품, 고난도 복합 제품으로 요구 범위를 넓히는 방향을 검토한다. 단계 수와 정확한 품목·수량은 별도 결정한다. 서브 발주는 비축과 판매 선택을 만드는 용도로 활용한다.

정밀 제어기, 산업용 펌프, 자동화 생산 모듈은 고난도 발주 품목 후보이며 최종 목표로 확정하지 않는다. 자원 해금과 제조법이 순환 의존하지 않도록 각 상위 제품을 만드는 데 필요한 시설과 토지를 해당 제품 없이 확보할 수 있어야 한다.

## 10. 아이템별 관리 항목

품목이 확정되면 다음 항목을 기록한다.

- 고유 식별자와 표시 이름.
- 확정·후보 상태와 자원 해금 단계.
- 원재료·중간재·완제품 구분.
- 채취 시설 또는 제조 시설.
- 제조 재료 목록과 이후에 정할 투입·산출 수량 및 처리 시간.
- 직접 투입 재료 종류 수와 제작 티어, 정제 공정 해당 여부.
- 다음 제조법에서의 사용처와 일반 판매 가능 여부.
- 메인·서브 발주 후보 여부.
- 이후에 정할 판매가, 적재·저장 단위와 아이콘.

정수 수량과 품목별 적재량을 사용하는 방식은 앞선 검토안이며 아직 확정하지 않는다. 제조 관계를 먼저 정하고 경제·물류 수치는 프로토타입에서 맞춘다.

## 11. 다음 결정 순서

1. 돌, 원목, 석판, 판재, 석재 테이블의 초기 5종 후보를 검토한다.
2. 석재 테이블을 첫 복합 상품으로 사용할지 다른 돌·나무 조합 상품으로 바꿀지 정한다.
3. 석탄 단계에 연탄 같은 독립적인 가공 상품을 둘지 정한다.
4. 철 생산의 기본 중간재와 목재 결합 상품을 선택한다.
5. 구리·금·석유·석영의 해금 순서와 각 파생 품목을 검토한다.
6. 원유 정제의 단일·복수 산출 방식과 액체의 저장·운송 표현을 정한다.
7. 상위 3종·4종 조합 후보를 검토하고 시설별 입력 저장 방식을 정한다.
8. 초기 생산 경험을 확인한 후 메인 발주 최종 품목을 선정한다.
